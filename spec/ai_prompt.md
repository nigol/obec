# Prompty

## Entita

Ahoj, potřebuji, abys mi napsal JPA Java classu, která bude reprezentovat entitu. Tabulka se bude jmenovat OB_PAYMENT_TYPE. Budou tam 2 atributy:

- Id: typu long (opravdu malý long a ne class Long)
- label: typu String s maximální délkou 300

Vygenereuj taky standardní metody jako equals (pouze podle Id) a toString. JPA classa musí být Serializable. Použij package z JavyEE 7. Pro odsazení použij znak TAB a ne mezery.
